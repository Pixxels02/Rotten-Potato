# Rotten-Potato
Watchlist Ersteller für Serien und Filme. Diese Seite soll die Möglichkeit geben Filme und Serien in eine Liste einzutragen und diese mit einem Status und einer Bewertung zu versehen. Außerdem gibt es einen Button der dem Nutzer einen zufälligen Film/Serie aus der Liste gibt.

## Starten
`index.html` im Browser öffnen.
